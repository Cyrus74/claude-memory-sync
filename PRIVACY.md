# Privacy Policy — Claude Memory Sync

Claude Memory Sync is a personal, single-user tool. It runs on the owner's own computer and
uploads the owner's own notes to the owner's own Google Drive.

- It requests only the `drive.file` scope: it can see and modify only the files and folders it
  creates itself in the owner's Google Drive.
- No data is sent to, stored on, or shared with any third party or server.
- Credentials are stored locally on the owner's computer and never leave it.
- The tool is not offered to other users.
